Raw `powermetrics` logs from `scripts/power-baseline.sh` (gitignored, root-owned until chowned). Summaries go in SPEC.md §13.1.9; `scripts/power-baseline.sh --parse FILE` replays one.

`2026-09-21-powermetrics-20x1s.txt` is the one tracked capture: the raw output of `sudo powermetrics --samplers cpu_power,gpu_power -i 1000 -n 20` (twenty one-second samples), run by Connor on 2026-09-21 while `glowtop-probe energy` recorded the same seconds. It is the cross-check behind SPEC.md §5.6.3. All 20 seconds paired; the GPU means agreed (0.021 W from GlowTop against 0.022 W from `powermetrics`, ratio 1.04), and CPU power agreed on each of the 16 quiet seconds — the four spike seconds differ only by which side of a one-second boundary the spike fell on. That confirmed the energy unit constant for the CPU and GPU channels and let 1.1.2 drop the Power card's `uncertain` label; ANE and DRAM share the same unit handling and were not independently sampled. The file's header gives the machine model, OS build and boot time; it carries no user name, host name or serial number.
